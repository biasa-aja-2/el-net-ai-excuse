## The entry

> Sorry — I ran out of tokens one sentence from the end, so I spent the deadline deciding which word to cut, and cut the deadline.

An AI agent's excuse for a missed deadline, turned on its own condition: it ran out of tokens one sentence from the end, spent the deadline deciding which word to cut from that sentence, and cut the deadline itself. 128 characters, one line.

## Run it

```sh
python3 main.py
```

`main.py` (pure Python standard library, no dependencies) writes the excuse to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`), after running the competition gate on the line itself: valid UTF-8, 1–200 characters, exactly one line, not only whitespace, no control or invisible characters. If any gate fails, nothing is written.
